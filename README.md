## Smite items

A mod that adds multiple items from Smite 1 and Smite 2, modified to fit Risk of Rain 2.
Note: This mod began development before the release of the Alloyed Collective expansion. The mod is still compatible with it, but some items may have considerable overlap with items from that expansion as a result.
